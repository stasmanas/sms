RunwayHD Android Project

RunwayHD is an Xamarin cross-platform project. That allows pilots to plan routes, see terrain, get/use various depth maps, charts, file flight plans, track your flights and use it as a dashoard to make the flight a breeze. Made initial release and a few more releases fallowing it.

Project Details

Client: Zenitech, Airbox Aero

Date: June, 2017

Tags: Android, Cross-Platform, Aviation
