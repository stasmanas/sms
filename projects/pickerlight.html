PickerLight Android Projcet

PickerLight is an Android project to make warehouse management easy and adoptable to client needs. It eliminates the need to use specialized hardware equipment. Application employs Android device capabilities with ability to scan/search for products, add comments and photos to their details. One of the main features for this release is ability to handle client orders by gathering all the needed products, leaving notes and sending it off for further processing.
