Whispers

Whispers is project with a romantic and interesting idea about broadcasting human heritage into space. We have developed the website and video TS generation server for DVB-S satellite broadcasting. All running on Google Cloud and MEAN development stack. Ready for scaling on public cloud infrastructure.
